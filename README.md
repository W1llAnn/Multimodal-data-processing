## Найденные ошибки (кратко; полный разбор механизмов — в `dz1-bughunt.ipynb`)

| # | Где | Что сломано | Исправление |
|---|---|---|---|
| 1 | `sinusoidal_positional_encoding` | позиции нумеруются с 1: нулевой токен получает код позиции 1, вся решётка фаз сдвинута на шаг | `torch.arange(length)` вместо `torch.arange(1, length + 1)` |
| 2 | `LayerNorm.forward` | статистики по оси батча (`dim=0`) вместо признаков токена (`dim=-1`): норма зависит от соседей по батчу, а при батче из 1 (генерация) слой отдаёт константу — представления схлопываются | `dim=-1` в `mean` и `var` |
| 3 | `scaled_dot_product_attention` | softmax по оси запросов (`dim=-2`): распределением становится столбец, а не строка; выход перестаёт быть выпуклой комбинацией V | `softmax(..., dim=-1)` |

Диагностический прогон до исправления: 7 из 17 (упало 10 проверок). После исправления — 17 из 17.

## Воспроизведение

### Локально (так получены приложенные результаты)

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate     Linux/macOS:  source .venv/bin/activate
pip install -r requirements.txt
jupyter lab          # открыть оба ноутбука и выполнить все ячейки сверху вниз
```

Вариант без Jupyter (прогон с сохранением выводов ячеек):

```bash
python -m jupyter nbconvert --to notebook --execute --inplace dz1-attention.ipynb
python -m jupyter nbconvert --to notebook --execute --inplace dz1-bughunt.ipynb
```

### Google Colab

Загрузить оба ноутбука в Colab (бесплатный тариф, CPU или T4), `Runtime → Run all`.
Код не использует GPU-специфику, `torch` в Colab предустановлен; первая ячейка
самостоятельно ставит его при локальном запуске.
